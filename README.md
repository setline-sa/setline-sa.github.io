# موقع سِت لاين — SETLINE Website

موقع ثابت (HTML/CSS/JS) بالعربي والإنجليزي، مبني على دليل الهوية v1.2.

## الملفات
| الملف | المحتوى |
|---|---|
| `index.html` | هيكل الصفحة |
| `styles.css` | الألوان والخطوط والتنسيق (حسب دليل الهوية) |
| `data.js` | **كل النصوص والمشاريع والفريق والعملاء** — عدّل هنا |
| `app.js` | تبديل اللغة، فلترة المشاريع، معرض الصور، نموذج التواصل |
| `assets/projects/` | صور المشاريع `pNN_1..3.jpg` (مستخرجة من ملف "أعمالنا") |
| `assets/brand/` | الشعار والرمز |

## إضافة مشروع جديد
1. ضع 3 صور باسم `p19_1.jpg`, `p19_2.jpg`, `p19_3.jpg` في `assets/projects/`.
2. انسخ أي مشروع في `data.js` وغيّر `n: 19` والنصوص.

## التشغيل محلياً
```
python -m http.server 8080 --directory website
```
ثم افتح http://localhost:8080

## النشر
ارفع محتوى مجلد `website` كما هو على أي استضافة (Netlify / Vercel / cPanel) واربطه بنطاق `setline.sa`.
